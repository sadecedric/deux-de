# Under & Over 7

Application Flutter Android et prédicteur web. Les comptes sont gérés avec
Supabase. Les prédictions des comptes connectés sont partagées entre le site
et l'application ; le mode local sert aux tests sans serveur.

## Déploiement du prédicteur

Le guide [DEPLOIEMENT_PREDICTEUR.md](DEPLOIEMENT_PREDICTEUR.md) décrit la migration
Supabase, le déploiement Vercel et la mise à jour de l'APK à distribuer.
